About This App

ATX Quote Builder v2.0
Internal estimate-development tool for AeroTerraX Land Solutions.

Implements the approved ATX-PRICE-001 v2.0 pricing architecture: Base Fee + (Scoped Acreage × Approved Per-Acre Rate) + Applicable Options / Direct Costs.

The former universal complexity multiplier, Property Screening, standalone GIS offerings, NRCS reimbursement-pattern calculation, and editable local pricing have been retired from the v2.0 quote workflow.

NRCS relationship: NRCS payment schedules may support internal benchmarking, but they do not dictate the ATX professional-service fee and this app does not estimate or promise client reimbursement.

Data storage: Estimate history is stored locally using browser localStorage. Nothing is transmitted by the app. Clearing browser data will erase history.

Email delivery: Email Estimate Summary opens the device's default mail application with a pre-filled estimate. Review it before sending.

Companion controls: ATX-PRICE-001 v2.0 (authoritative Word framework); ATX-PRICE-001 Quote Builder v2.0 (Excel); ATX Pricing Reference - Quicken v2.0.

Scope Rules

  • PLI and LAnDS standard formulas apply through 200 acres; larger engagements require individual scoping.
  • LAnDS field validation is an optional $500 add-on; applicable travel remains separate.
  • Precision Soil Testing wet-lab analysis is $22 per required composite sample, including shipping.
  • Compaction testing is not part of the Precision Soil Testing offering.
  • Prescribed Fire Planning is planning only; implementation, Burn Boss services, personnel, equipment, and execution are excluded.
  • Physical map printing is optional vendor fulfillment/pass-through.
  • GIS is an embedded technical capability, not a standalone ATX offering.
  • Atypical scope is reviewed individually rather than handled with a complexity multiplier.

Deployment

  1. Replace the repository's existing index.html with this v2.0 file.
  2. Commit and push to the branch used by GitHub Pages.
  3. Open the deployed page and hard-refresh once to ensure the new file is loaded.
  4. Saved v1.0 history may remain in localStorage, but v2.0 automatically separates its history under a new storage key.
